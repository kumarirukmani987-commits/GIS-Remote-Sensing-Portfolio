# DEM and Terrain Analysis

## Project Overview

This project presents a GIS-based analysis of terrain characteristics using a Digital Elevation Model (DEM).

## Objectives

- Analyze elevation variation.
- Generate terrain-related thematic maps.
- Derive slope and aspect.
- Analyze drainage and terrain characteristics.
- Support watershed and hydrological analysis.

## Data

Digital Elevation Model (DEM) data were used for terrain analysis and generation of derived spatial datasets.

## Software

- QGIS
- GIS
- Remote Sensing

## Analysis

The project includes:

- DEM preprocessing
- Elevation analysis
- Slope generation
- Aspect generation
- Hillshade generation
- Contour generation
- Drainage analysis
- Watershed delineation

## Outputs

- Digital Elevation Model
- Slope map
- Aspect map
- Hillshade map
- Contour map
- Drainage network
- Watershed map
