# Land Surface Temperature (LST) Analysis

## Project Overview

This project presents a Remote Sensing and GIS based analysis of Land Surface Temperature (LST) to investigate spatial and temporal variations in surface temperature.

## Objectives

- Derive Land Surface Temperature from satellite imagery.
- Analyze spatial variation in surface temperature.
- Identify relatively higher and lower temperature zones.
- Examine the relationship between LST and vegetation.
- Prepare thematic LST maps.

## Data

Satellite imagery was used to derive Land Surface Temperature and analyze its spatial distribution.

## Software

- QGIS
- Remote Sensing
- GIS

## Analysis

The project includes:

- Satellite image preprocessing
- Land Surface Temperature retrieval
- Raster calculation
- Spatial analysis
- LST classification
- Temporal comparison
- Thematic map preparation

## Relationship with Vegetation

LST can be examined alongside NDVI to investigate the spatial relationship between vegetation conditions and surface temperature.

## Outputs

- LST thematic maps
- Spatial temperature analysis
- Temporal LST comparison
- GIS-based visualization
