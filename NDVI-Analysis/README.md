# NDVI Analysis

## Project Overview

This project presents a Remote Sensing based analysis of vegetation conditions using the Normalized Difference Vegetation Index (NDVI).

## Objectives

- Calculate NDVI from satellite imagery.
- Assess spatial variation in vegetation conditions.
- Analyze temporal changes in vegetation.
- Prepare NDVI thematic maps.
- Identify areas of relatively higher and lower vegetation density.

## NDVI Formula

NDVI is calculated as:

NDVI = (NIR - Red) / (NIR + Red)

## Data

Satellite imagery was used to derive NDVI and assess vegetation characteristics.

## Software

- QGIS
- Remote Sensing
- GIS

## Analysis

The project includes:

- Satellite image preprocessing
- NDVI calculation
- Raster analysis
- NDVI classification
- Temporal comparison
- Thematic map preparation
